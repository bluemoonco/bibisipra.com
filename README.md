# bibisipra.com

Recruiter-focused professional website for Bibi Sipra, CPA: US corporate tax and multinational tax leadership opportunities in Southeast Asia.

- `public/` — complete static website; publish this directory.
- `docs/AUDIT.md` — production audit, copy strategy, evidence and validation limits.
- `docs/DEPLOYMENT.md` — publishing settings and post-deployment checks.

No install or build step is required. Preview with `python3 -m http.server 8765 --directory public`.

The canonical URL remains `https://www.bibisipra.com/`. GitHub commits alone do not update the existing Weebly site unless a publishing integration is configured.
